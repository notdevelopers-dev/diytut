# Фронтенд

React + TypeScript + Vite. Бекенд піднімається за інструкцією в [головному README](../README.md#швидкий-старт).

## Запуск

Є два рівноцінні способи:

- **З Node.js на машині:** встановити залежності з lock-файлу і запустити dev-сервер Vite. Потрібна версія Node зафіксована в репозиторії.
- **У контейнері, без Node:** Vite запускається разом з рештою стеку через профіль Docker Compose `web`. Профіль можна вмикати разово або один раз прописати в локальному файлі оточення. Залежності в контейнері синхронізуються з lock-файлом при кожному старті й живуть окремо від локальних, бо частина пакетів містить скомпільовані під конкретну ОС файли.

В обох випадках сайт відкривається на порту **5173**, а зміни в коді підхоплюються одразу.

## Залежності

- Використовуємо лише **npm**, щоб не було кількох lock-файлів.
- Для звичайного встановлення — чисте встановлення з lock-файлу; додавання пакета — лише коли справді потрібна нова залежність.
- Нові залежності автоматично записуються з точною версією.
- **TypeScript** і рушій type-aware перевірок **Oxlint** оновлюються лише разом: версія рушія відповідає конкретній версії TypeScript. Dependabot приносить їх одним PR — перевіряйте, що вони відповідають одна одній.

## Скрипти

- `dev` — dev-сервер з автооновленням
- `build` — перевірка типів і продакшн-збирання
- `typecheck` — лише перевірка типів
- `lint` — Oxlint, разом із правилами, що враховують типи
- `format` / `format:check` — відформатувати код / лише перевірити форматування
- `preview` — переглянути зібрану версію локально

Перед комітом мають проходити `format:check`, `lint` і `build`.

## Звернення до API

- **У коді — лише відносні шляхи** під `/api`, без домену й порту. У розробці їх пересилає на бекенд Vite, у продакшні — nginx, тож код однаковий для обох середовищ і CORS не потрібен.
- Адресу бекенду для проксі Vite можна перевизначити змінною оточення `API_PROXY_TARGET`.
- Автодокументація API доступна через той самий проксі за адресою `/api/docs`.

## Змінні оточення

Змінні з префіксом `VITE_` потрапляють у код, який завантажує браузер. Тому не ставте секрети в них: усе, що бачить фронтенд, бачить і будь-який користувач.

## Редактор (VS Code)

Рекомендовані розширення VS Code запропонує сам при відкритті репозиторію:

- **TypeScript 7** (Microsoft) — мовний сервер TypeScript;
- **Oxc** — підсвічування помилок Oxlint;
- **Prettier** — форматування.
